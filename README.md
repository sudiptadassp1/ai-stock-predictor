Predict possible WooCommerce product stockouts using recent sales trends and current inventory.

== Description ==

Aura Stock Forecast for WooCommerce helps WooCommerce store owners identify products that may run out of stock soon.

The plugin analyzes recent sales history and current inventory levels to estimate stockout dates, risk levels, and suggested reorder quantities directly from the WordPress admin dashboard.

= Features =

* WooCommerce product inventory dashboard
* Estimated stockout date for each product
* Risk level indicators: High, Medium, Low, and Unknown
* Suggested reorder quantity
* Recent sales trend analysis
* Pagination for large product catalogs
* Works inside the WordPress admin area

= Free vs Pro =

The free version provides essential stockout forecasting for WooCommerce products.

A Pro version is planned for CodeCanyon and may include advanced forecasting options, configurable lead times, export tools, variation-level analytics, supplier management, and extended reporting.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/aura-stock-forecast-for-woocommerce/` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the Plugins screen in WordPress.
3. Make sure WooCommerce is installed and active.
4. Go to WooCommerce > Aura Stock Forecast in the WordPress admin menu.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. WooCommerce must be installed and active.

= Does the plugin use external services? =

No. The free version calculates predictions locally using WooCommerce order and stock data.

= Will it change my stock quantities? =

No. The plugin only displays predictions and does not modify product inventory.

= Can I configure supplier lead time? =

This is planned for the Pro version.
